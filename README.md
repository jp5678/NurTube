# NurTube

간호대학생을 위한 **[AI융합 간호정보학]** 영상 큐레이션 사이트.
수업 목표로 후보를 모으고, **국내외 시청자 댓글·좋아요 분석**으로 우선순위를 정했습니다.

## 구성
- 영상 116편 (4개 영역 · 13개 주제, 한국어 40편), 반응 점수 순으로 정렬
- 영상마다: 상세 요약 · 추천 이유 · 토론 질문과 펼쳐 보는 답변 가이드 · 시청자 반응 점수와 댓글 분석 요약
- **한국어로 보기**: 카드마다 `한국어`(음성) · `한글 자막` · `자동번역 자막` 배지, '한국어 시청' 필터, 영상 열 때 한국어 자막 자동 켜기
- **15주 로드맵 + 주차별 확인 퀴즈**(5~7문항, 총 87문항, 해설 포함). 15주차는 디지털 헬스케어·원격의료
- **시간 표시 학습노트**: '⏱ 현재 시간 넣기'(단축키 `t`)로 `[12:34]` 기록, 누르면 그 장면으로 이동
- **LMS 제출용 Word(.docx)**: 제출자 정보(이름·학번·분반), 학습 현황(영상 시청·퀴즈 점수), 노트, 시간 링크
- **교수자 모드**: 영상 관리(추가·수정·숨김·주차 이동), 🔎 추천 후보(새 영상 자동 찾기 + Claude AI 초안), 교수 검수 배지
- 2026 국내외 최신 동향, 학습 자원, AI 사용 5원칙
- 학생 데이터(노트·퀴즈·좋아요·기록)는 각자 브라우저에만 저장됩니다. 서버·로그인이 없습니다.

## 실행
```bash
python3 -m http.server 8765
```
이후 http://localhost:8765 접속. YouTube 재생과 시간 기능은 `file://`이 아니라 웹 서버로 열어야 동작합니다.
글꼴(Pretendard)과 Word 내보내기 라이브러리(JSZip)는 프로젝트 안에 들어 있어 외부 CDN이 막힌 학교망에서도 디자인과 내보내기가 유지됩니다.

## LMS 제출 방식 (학생 안내)
1. 영상 페이지에서 학습노트를 적고, 로드맵에서 주차별 퀴즈를 풉니다.
2. **학습노트** 메뉴에서 분반·학번·이름을 입력하고 **Word(.docx) 내보내기**를 누릅니다.
   파일 이름: `NurTube_학습노트_학번_이름_날짜.docx`
3. (선택) 구글 드라이브에 올려 **Google 문서로 열기** → 편집 → **파일 → 다운로드 → Microsoft Word(.docx)**
4. LMS 과제 제출란에 .docx 파일을 업로드합니다.

## 교수자 도구: 버튼으로 관리하기
### 영상 추가 · 수정 · 숨기기 · 주차 이동
1. 사이트 **설정 → 교수자 모드**를 켜면 메뉴에 **✏️ 영상 관리**가 나타납니다.
2. YouTube 주소를 붙여 넣고 **불러오기**(제목·채널 자동 입력) → 주제·수준·로드맵 주차·요약·추천 이유·토론 질문·답변 가이드 입력 → **저장**.
   기존 영상의 글 수정, 주차 이동, 학생 화면에서 숨기기, 교수 검수 표시도 할 수 있고, 저장하면 이 브라우저에서 바로 미리 봅니다.
3. **반영 파일 내보내기** → 다운로드 폴더에 `nurtube-update-날짜.json` 저장
4. NurTube 폴더의 **`NurTube 업데이트.command`를 더블클릭** → **1번**
   → 파일 검증·병합 → 새 영상 반응 점수 수집 → 사이트 데이터 재생성 → (확인 후) GitHub 업로드
5. 반영이 끝나면 영상 관리 화면에서 **변경 목록 비우기**

### 새 영상 찾기 + AI 초안 (자동 추천)
1. (최초 1회) 메뉴 **5번 AI 설정**에서 Claude API 키를 등록합니다. 키는 macOS 키체인에만 저장되며 파일·GitHub에 남지 않습니다.
2. 메뉴 **2번 새 영상 찾기**: 주제별 검색어(`tools/discovery.json`)로 최근 2년 영상을 찾아 반응 점수를 매기고,
   같은 주제에서 점수가 가장 낮은 기존 영상(교수 검수 영상 제외)과 비교합니다. Claude가 영상 설명란·시청자 댓글을 바탕으로
   요약·추천 이유·토론 질문·답변 가이드·반응 요약 초안과 '확인할 점'을 씁니다.
3. 사이트 **영상 관리 → 🔎 추천 후보**에서 후보마다 **검토 후 추가 / 기존 영상과 교체 / 제외** 중 하나를 누릅니다.
   추가·교체는 AI 초안이 채워진 편집 화면이 열리니, **영상을 보고 확인·수정한 뒤 저장**하세요. 교체하면 기존 영상은 숨겨지고 그 주차를 이어받습니다.
4. 반영 파일 내보내기 → 메뉴 **1번**으로 반영·업로드
- 자막은 YouTube 정책상 가져올 수 없어, AI는 영상을 직접 보지 않고 설명란·댓글만으로 초안을 씁니다. 그래서 자동 교체는 하지 않고 교수자 확인을 거칩니다.
- Claude API 사용료가 듭니다(후보 1편당 1회 호출, 기본 2편 × 13주제). 모델은 `tools/ai_config.json`의 `"model"`로 바꿀 수 있습니다(기본 `claude-opus-5-5`).

### 메뉴 (`NurTube 업데이트.command`)
| 번호 | 하는 일 |
|---|---|
| 1 | 영상 관리 변경사항 반영 + GitHub 업로드 |
| 2 | 새 영상 찾기 + AI 초안 → 사이트 '추천 후보'에 표시 |
| 3 | 학기 점검: 전체 반응 재수집·삭제/비공개 영상 점검 + 업로드 (`tools/refresh-report.md` 보고서) |
| 4 | 내 컴퓨터에서 사이트 미리보기 |
| 5 | AI 설정: Claude API 키 등록(키체인)·연결 확인, 필요한 패키지 설치 |
| 6 | GitHub 처음 연결: 공개 저장소 생성 + GitHub Pages 켜기 (최초 1회, GitHub CLI `gh` 로그인 필요) |

- YouTube가 요청을 제한하면(HTTP 429) 자동으로 쉬었다 다시 시도하고, 학기 점검에서 실패가 20%를 넘으면 기존 데이터를 그대로 두고 중단합니다.
- 새 영상의 반응 수집에 실패하면 '점수 대기'로 게시하고 다음 업데이트 때 다시 시도합니다.
- 업로드에서 제외되는 파일(댓글 원문 `tools/raw.json`·`tools/digest.txt`, 반영 기록, 작업 설정)은 `.gitignore`에 들어 있습니다.

### 직접 파일로 고치고 싶을 때
- `tools/curated.json`: `topic`, `lv`, `q`, `rx`, `adj`(±점수 보정), `t`·`ch`(제목·채널을 바꿀 때만)
- `tools/details/*.json`: `sum`, `why`, `a` · `tools/overrides.json`: 숨김·주차 이동 · `tools/reviewed.json`: 교수 검수
- 로드맵 기본 구성은 `js/data/taxonomy.js`, 퀴즈는 `js/data/quizzes.js`. 고친 뒤 `python3 tools/build_data.py`
- 후보 영상 찾기: `python3 tools/search.py "원격의료 간호"`

## 반응 점수 (100점)
| 항목 | 배점 |
|---|---|
| 좋아요율 (좋아요/조회수, 4%면 만점) | 25 |
| 좋아요 규모 (1만이면 만점) | 20 |
| 상위 댓글의 학습·추천 반응 (긍정 − 0.7×부정, 소표본 보정) | 30 |
| 학습자·의료인 댓글 비율 | 15 |
| 댓글 규모 | 10 |

자동 점수에 댓글을 직접 읽고 판단한 보정(±4점, `adj`)을 더합니다. 사이트에는 댓글 원문을 싣지 않습니다.
`tools/raw.json`, `tools/digest.txt`에는 댓글 원문이 있으니 배포 폴더에 올리지 마세요.

## 배포
교수자 도구 4번(GitHub 처음 연결)으로 GitHub Pages에 올립니다. 정적 파일이라 Netlify, Cloudflare Pages에 올려도 됩니다.
